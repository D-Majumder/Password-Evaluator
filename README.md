# Password Evaluator

A Python script that assesses the strength of a password and provides feedback.

## Overview

This password evaluator is a Python script designed to assess the strength of user-generated passwords and provide feedback on their security. It performs a series of checks to determine the robustness of a password based on criteria such as length, complexity, and character variety.

## Features

- Length check
- Character variety check (uppercase, lowercase, digits, symbols)
- Feedback and recommendations for improving a weak password

## Setup

No third-party dependencies are required — the script uses only Python's standard library (`re`).

```bash
git clone https://github.com/D-Majumder/password-evaluator.git
cd password-evaluator
python "Password Evaluate.py"
```
